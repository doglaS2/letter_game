# Guia de Contribuição

Obrigado pelo seu interesse em contribuir com o Jogo das Letras! Este documento fornece diretrizes e instruções para contribuir com o projeto.

## Como Contribuir

1. Faça um Fork do projeto
2. Crie uma Branch para sua Feature (`git checkout -b feature/AmazingFeature`)
3. Faça Commit das suas mudanças (`git commit -m 'Add some AmazingFeature'`)
4. Faça Push para a Branch (`git push origin feature/AmazingFeature`)
5. Abra um Pull Request

## Padrões de Código

- Use nomes descritivos para variáveis e métodos
- Mantenha o código organizado e bem comentado
- Siga as convenções de código Java
- Mantenha as classes pequenas e focadas em uma única responsabilidade

## Estrutura do Projeto

- `src/models/`: Classes de modelo
- `src/utils/`: Classes utilitárias
- `src/game/`: Lógica principal do jogo

## Testes

- Adicione testes para novas funcionalidades
- Mantenha a cobertura de testes existente
- Execute todos os testes antes de submeter um PR

## Documentação

- Atualize a documentação quando necessário
- Mantenha o README.md atualizado
- Documente novas funcionalidades

## Issues

- Use o template de issue apropriado
- Forneça detalhes suficientes para reproduzir o problema
- Inclua screenshots quando relevante

## Pull Requests

- Descreva claramente as mudanças
- Referencie issues relacionadas
- Inclua screenshots para mudanças visuais

## Licença

Ao contribuir, você concorda que suas contribuições serão licenciadas sob a mesma licença MIT do projeto.
